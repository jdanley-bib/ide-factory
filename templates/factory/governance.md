# Governance

- The human authors OpenSpec changes. The factory does not invent products.
- Backlog.md is the only execution queue. `.factory/` stores team memory, not tasks.
- The reviewer is a different role from the engineer who implemented the task.
- Do not edit `GOLDEN_RULES.md`. Append to `decisions.md` and agent histories.
- Spend, publishing, deployment, and new accounts require `idefactory approve`.
- A `HALT` file in the project root stops `next` and `sync-tasks`.
- One IDE session writes `.factory/` at a time. Git merges concurrent edits.
