## IDE Factory

This project uses the IDE-native factory. Team memory is `.factory/`. The human defines work in OpenSpec. Backlog.md is the only execution queue. The IDE's own model does the work.

- Cursor rule: `.cursor/rules/factory.mdc`
- Skills: `factory-coordinator`, `factory-openspec`, `factory-build`, `factory-governance`
- Commands: `/factory-status`, `/factory-plan`, `/factory-build`, `/factory-review`
- Do not start Ollama. Do not invent a product from the web.
- At the start of factory work, run `backlog instructions overview` if you have not read it this session.
- Do not edit `GOLDEN_RULES.md`. Append to `.factory/decisions.md` and agent histories.
