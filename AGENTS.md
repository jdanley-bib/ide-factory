## IDE Factory

This project uses the IDE-native factory. Team memory is `.factory/`. The human defines work in OpenSpec. `.factory/work/` is the only execution queue. The IDE's own model does the work.

- Cursor rule: `.cursor/rules/factory.mdc`
- Skills: `factory-coordinator`, `factory-openspec`, `factory-build`, `factory-run`, `factory-governance`
- Commands: `/factory-status`, `/factory-plan`, `/factory-build`, `/factory-run`, `/factory-review`
- Do not start Ollama. Do not invent a product from the web.
- Read `.factory/governance.md` for the operational baseline.
- Append to `.factory/decisions.md` and agent histories. Do not truncate them.
